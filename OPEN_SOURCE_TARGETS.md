## 🎯 Selection & Filtering Criteria
- **YC-Backed & Core Open Source**: Venture-backed, production-grade tools with core product source on GitHub.
- **Moderate Contributor Base**: Bypassed "big fish" (500+ contributors) where PRs sit in triage noise. Focused on 30–150 contributor bases for maximum maintainer visibility.
- **Active Velocity**: Recency within ~2 months (most committed within days).
- **Verified Hiring Signals**: Confirmed active openings via YC *Work at a Startup* and official company careers pages.

## 🎮 The 6-Week Contributor-to-Hire Execution Playbook

```
Week 1: Initial PR ──► Weeks 2-4: Deep Issues ──► Weeks 4-6: CTO Outreach
  - Join Discord/Slack   - Scoped issue resolution  - Direct email / DM
  - Fix typos / docs     - Comment approach first   - Share PR record
  - Build maintainer     - Help in Discord community- Apply on YC Startup
    trust fast
```

### 📌 Phased Steps:
1. **Week 1 (Low-Friction Start)**:
   - Join project Discord/Slack.
   - Run setup locally.
   - Submit a small PR (documentation fix, typo, flaky unit test fix) within 7 days to establish merged PR record.
2. **Weeks 2–4 (Core Issue Ownership)**:
   - Claim a real functional issue.
   - Comment your proposed design/approach before submitting code to align with core maintainers.
   - Answer technical community questions in Discord. Maintainers notice consistent community helpers.
3. **Weeks 4–6 (Direct Engineering Outreach)**:
   - Send a concise message directly to the CTO or Founder:
     - Summarize your 3-4 merged PRs.
     - Propose 1 high-value improvement for their roadmap.
     - Attach your resume / YC Work at a Startup profile.
